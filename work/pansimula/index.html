Galactic Thunderdome: achievements, by impact

  • Level design without codeA toolset of editor windows that let designers build whole levels without programming: the map, rock baking, item and enemy spawns, triggered events, linked zones, objectives and their balance, and which builds a map ships in. It's how the game got 40+ maps with several rule sets. The hardest mode, Gauntlet, got its own stage editor with validation and a test start at any stage. Watch the level tools. Watch the Gauntlet tool.
  • Destruction engineReshaping colliders at runtime is too expensive with dozens of objects breaking every frame, so fracture is Voronoi, baked in the editor, and the bake tool notices when a designer forgot to rebake. At runtime, pre-cached, forward-seeking fracture and pooled fragments keep memory steady around frame spikes. A baked trim pass hides rock edges covered by neighbours, saving about 5 ms of rendering with several hundred rocks. 600+ destructible objects at over 60 fps on Steam Deck.
  • Frame-budgeted job queueGeneric actions run through a queue with a per-frame budget, split between the main thread and worker threads, and the budget grows in pause menus and other quiet moments. Pools prepare complex objects in stages and refill when nothing is happening. Maps of 4,000+ objects load in under 4 seconds.
  • Modular weapons80+ weapons assembled from 172 reusable modules: muzzle flash, reload, ammo, sounds, lights. Designers lay out each weapon's states in Unity's Animator; a baker turns that into data for a generic state machine, which calls each module's methods by state name through cached reflection. Developers build modules in isolation.
  • One-click releaseChecks every bake is current and every localization key exists in every language, sets the right compile flags for demo, Steam or recording builds, builds, and uploads to Steam. A setup tool configures other developers' machines. Watch the video.
  • Game flow as a state machineReworked years of managers calling each other into one top-level state machine, where each state says which managers run and when, and documented it for the team.
  • Quick test launcherLaunch any map with any items and rules without playing through the game. The menu is built from the files on disk, so it grows with the content. Watch the video.
  • AI pathfinding toolsAn A* baker that builds node maps automatically, links doors to their buttons and supports danger weights and one-way paths, plus a live view of nodes, weights and AI paths for balancing. Watch the baker. Watch the live view.
  • Localization in 10 languagesA tool machine-translates all game text and imports it back so translators only polish, and another generates only the font glyphs the text uses, which matters most for Simplified Chinese.
  • AudioMade over 400 of the game's sounds in under 2 months alongside my main work, including procedural ones that scale with impact and damage. Rock-destruction sounds are merged and layered by size and how the rock breaks. An editor tool versions and balances the volume of 800+ sounds.
  • Reflection cachingCut reflection overhead from 60× to 1.2–1.6×.
