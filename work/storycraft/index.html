Achievements, by impact

  • Cutting the crash rate by 73% A per-launch crash census and memory tooling first, then memory management, server-side image processing and async world loading.5.5% → 1.5%
  • Overnight test runner Device tests whose plans update when the game changes, and agents that fix what fails and queue the fixes for review.up to 12 h unattended
  • Multi-editor runner Three Unity editors per developer, each with its own agent, environment and backend, with a task queue, a resource manager and a CLI bridge into the editor.3 editors / developer
  • Game features from design specsMany of the game's player-facing features: quests, currency and progression, leaderboards, player profiles, interior rooms, object manipulation, an announcement tool and plenty of UI screens.
  • Player telemetry and bug reportsEvery action a player takes is mapped and linked by id to the backend transactions behind it, alongside Amplitude tracking for conversion and player behaviour and AppsFlyer attribution the product team used for ad campaigns. A bug-report tool gathers it all from every source, so developers and AI debugging agents can piece together what happened.
  • Weekly release pipelineUnity batch build → Xcode archive → TestFlight, with debug symbols sent to Sentry. A headless Claude drafts release notes, the master list and the test plan from the commits.
  • MonitoringCrash, release, regression and log dashboards; Sentry and Jira data piped into BigQuery; Discord alerts. An agent can also monitor players overnight, catch issues before anyone reports them, and draft a task list for review before it goes to Jira.
  • Agent guardrailsClaude Code hooks that compile-check every C# edit and block error dialogs, coding standards and tiered agent docs, and a multi-pass code review with blast-radius analysis.
  • Online multiplayer and network resilienceEvery feature had to work online: players visit each other's worlds and chat there, mostly over WebSockets. Server-sent event streaming and WebSocket reconnects were tested by automated chaos-monkey simulations that inject network failures.
